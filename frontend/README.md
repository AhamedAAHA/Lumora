# Lumora Frontend

React + Vite + Tailwind CSS + GSAP landing page and interview app.

## Commands

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

## Environment

Copy `.env.example` to `.env` if needed:

```
VITE_API_URL=/api
```

The Vite dev server proxies `/api` to `http://localhost:5000`.
